Craft de interfaces, uma aula por conceito.

Os detalhes que fazem um software parecer certo: tipografia, cor, layout e movimento. Cada aula traz o porquê, o como e uma demo em CSS puro. Conteúdo sintetizado a partir de fontes confiáveis da comunidade de craft, com links no fim de cada aula.

As demos são UI de verdade: passe o mouse, clique, arraste e role os objetos. Sliders e switches mudam uma propriedade por vez.
